## Task 12 – KMeans: Customer Segmentation

### Tools Used
- Python
- Scikit-learn
- Matplotlib, Seaborn

### Work Done
- Loaded Mall Customers dataset
- Selected income and spending features
- Scaled features using StandardScaler
- Used Elbow method to find optimal K
- Applied KMeans clustering
- Visualized customer segments
- Interpreted clusters as customer types

### Outcome
Identified meaningful customer segments for targeted marketing.
